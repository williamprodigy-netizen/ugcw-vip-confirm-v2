BUILD NOTES · INTERNAL

How to build this page

This page is the VIP confirmation page. A lead lands here the second they buy the VIP ticket. The design and the copy are finished, do not rewrite the words.

The page is served from GitHub Pages at vipconfirm.ugc-world.com and shown inside a GHL funnel at ugc-world.com/vipconfirm. Merge fields do not survive an iframe, so nothing personal is written into the HTML. GHL resolves the tokens in the funnel body tracking code and passes them through the iframe URL, and the page reads them off the query string. That tracking code block is the only place you edit.

You are seeing this section because the URL has ?build=1 on it. Buyers never see it, and neither do the dashed token outlines. Nothing to delete before launch.

1. The tracking code block

Funnel > Settings > Body tracking code. Not page-level footer tracking, that one strips bare HTML elements and your iframe silently vanishes. Paste this, with the CSS that hides the GHL shell, and set the four Custom Values it references.

<style>#preview-container,.bg-fixed{display:none!important}</style> <iframe src="https://vipconfirm.ugc-world.com/?fn={{contact.first_name}}&amp;em={{contact.email}}&amp;cid={{contact.id}}&amp;cd={{custom_values.class_date}}&amp;ct={{custom_values.class_time}}&amp;cl={{custom_values.class_length}}&amp;cs={{custom_values.class_start_iso}}" style="position:fixed;top:0;left:0;width:100vw;height:100vh;border:0;z-index:2147483647"></iframe>

Never hide #__nuxt or use body > *:not(...). The custom code div is nested inside #__nuxt, so both rules hide your own iframe. It computes as visible while measuring 0x0, which is the tell.

3. The application form

The questions live in Typeform, not on this page. Form name VIP Typeform: DFY Portfolio Questionaire, id P2I1cnTV. The page just embeds it in an iframe. Nothing about the questions gets rebuilt in GHL.

  • Embed URL: https://form.typeform.com/to/P2I1cnTV with the three hidden fields appended, exactly as it already is in the iframe src.
  • Hidden fields: email_hidden, contact_id, first_name. They come off the GHL contact so a submission can be matched back without trusting what they type.
  • The form still asks for name, email and phone as visible questions. That is on purpose. If somebody opens the link fresh, outside the funnel, the hidden fields are empty and those answers are the only way to identify them.
  • Photos are five required upload questions, then three optional ones. Typeform takes one file per question, so every extra photo is another screen. Two optional video slots on top. This is a Typeform limit, not a design choice.
  • Name, email and phone are a single contact_info block, so all four inputs land on one screen instead of four. Socials are one free-text box, not one field per platform. 25 screens total. Do not add group wrappers, each one costs a wasted intro click.
  • The fallback link under the embed opens the form in a new tab. Leave it there, some in-app browsers block the iframe.
  • Do not edit the questions inside the GHL builder. Edit them in Typeform and the page picks the change up on its own.

4. What fires on submit

All of this hangs off a Typeform webhook, not off this page. The page has no submit handler and does not need one.

  1. Typeform webhook posts the response into GHL and writes the answers onto the contact.
  2. Tag the contact so the portfolio build workflow starts.
  3. Notify the fulfilment team that a new build is in the queue.
  4. The uploaded files come back as Typeform-hosted URLs in the webhook payload. Store them somewhere we own. Typeform file links are not a permanent home.
  5. Timestamp the submission. The promise is most portfolios back in about 20 minutes and 24 hours maximum, so the clock starts on the webhook.

5. Before you hand it back

  • Test on a phone first. Most VIP buyers open this on mobile.
  • Load it as a real contact and confirm the name in the text-message card is theirs, not "there". "there" means GHL did not resolve {{contact.first_name}} and the funnel has no contact context.
  • Click all three calendar buttons and confirm the .ics opens with the right date, time and length.
  • Submit the form end to end with real photos and confirm the webhook lands on the contact record.
  • Load the page as a real contact and confirm the three hidden fields arrive in the Typeform response, not blank.
  • Check the embed on an iPhone in the Instagram in-app browser. That is where iframes break.
  • Open the page WITHOUT ?build=1 and confirm no dashed outlines and no BUILD NOTES.
